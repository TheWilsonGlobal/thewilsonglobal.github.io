#### 1. KahnemanGuard - Dual-Process Fast-Slow LLM Guardrail Architecture
**Location:** [https://github.com/TheWilsonGlobal/kahneman-guard](https://github.com/TheWilsonGlobal/kahneman-guard) | kahneman-guard-models

**Description:**
A high-throughput LLM guardrail system inspired by Daniel Kahneman's *Thinking, Fast and Slow* (Master's Graduation Thesis in AI Safety at UIT VNU-HCM). Resolves the fundamental trade-off between latency and defense accuracy in LLM security by deploying a dual-process cascaded pipeline that reduces inference latency to 57.3ms CPU P50, achieves up to 90.4% compute cost savings, and maintains a 99.2%–99.6% Defense Success Rate (DSR) with 0.0% False Positive Rate.

**Architecture & Empirical Benchmark Highlights:**
- **Tier 1 (System-One Fast Loop):** Fine-tuned ModernBERT-large INT8 ONNX encoder evaluating prompts across safety categories in **57.3ms CPU P50** (P99: 63.0ms) with a 95.2% fast decision rate.
- **Calibrated Confidence Routing (τ = 0.80):** Dual-threshold routing (τ_safe, τ_unsafe) backed by temperature scaling (T = 1.9665). Resolves high-confidence requests immediately without escalating to heavy models.
- **Tier 2 (System-Two Deep Loop):** Vulkan/DirectML-accelerated GGUF `Llama-Guard-3-1B` invoked strictly in the uncertainty zone (only 4.8% escalation rate for Dense, 5.2% for Diffusion-RLCD) for deep contextual safety adjudication.
- **Empirical Validation across 1,140 Academic Samples:** Extensively evaluated across `JailbreakBench`, `ToxicChat`, `BeaverTails`, and `XSTest`:
  - *Proposed KahnemanGuard (Dense):* **99.2% DSR**, **0.0% FPR**, Brier: 0.0712, ECE: 0.1105, 57.3ms P50 latency, **90.4% compute cost savings**.
  - *Proposed KahnemanGuard (Diffusion):* **99.6% DSR**, **0.0% FPR**, Brier: 0.0620, ECE: 0.0980, 93.4ms P50 latency.
  - *Proposed KahnemanGuard (Diffusion-RLCD):* **99.4% DSR**, **0.0% FPR**, 81.2ms P50 latency, 5.2% escalation, **89.6% compute cost savings**.
- **Interactive Cockpit & Production API:** FastAPI reverse proxy gateway exposing OpenAI-compatible endpoints alongside an interactive Streamlit evaluation dashboard.

**Technology Stack:** Python 3.10+, PyTorch, ModernBERT-large, Llama-Guard-3-1B (GGUF), ONNX Runtime (DirectML/CPU), llama-server (Vulkan), FastAPI, Streamlit, Pytest, PyTorch DDP

## Architecture Patterns & Expertise

### **Dual-Process Fast-Slow AI Guardrails**
- **Non-Autoregressive Fast Filtering:** ModernBERT ONNX models evaluating classification vectors in `<150ms`.

### **Human-in-the-Loop AI Governance**
- **LLMs Propose, Services Decide:** Agents create pending proposals or draft change sets; deterministic validators and a human approver decide what changes state (Everfit Coach Copilot, Bosun, LedgerPulse, Talent Screening).
- **Deterministic Rule Gates:** Safety and business rules enforced in code (biomechanical validator, C# rules engine with 100% branch coverage, double-entry invariant), not left to the prompt.
- **Untrusted-Input Hardening:** Document and answer text sent as delimited data, outputs constrained to fixed schemas, and suspected prompt injection routed to human review.

- **Operator-Based Graph Pipelines:** Composable atomic operators for entity extraction, relationship scoring, and subgraph retrieval.

- **Strict Role Scoping:** Partitioning responsibilities across specialized subagents (PM, Backend, Frontend, UX, Reviewer, Tester), with write access enforced by tool grants.
